# Assignment 2 — Crimson Cup Cafe

## Reference Website

Name: Tim Hortons Pakistan

URL: https://timhortons.com.pk/

The website is inspired by a coffee-shop theme and a red-and-white colour palette. The brand name, content and implementation are original.

## Project Files

- index.html — Homepage with eight products
- product.html — Single product detail page
- style.css — Styling and responsive layout
- hero-coffee.png — Hero background image
- README.md — Project information

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## Bootstrap Usage

Bootstrap is used for the responsive grid and layout.

- col-12: one product per row on phones
- col-sm-6: two products per row on small screens
- col-lg-3: four products per row on large screens

## How to Run

1. Open the assignment folder in VS Code.
2. Keep hero-coffee.png in the same folder as index.html.
3. Open index.html in your browser.
4. Click a product image or name to open product.html.
5. Test at 375px, 768px and desktop widths.

Internet access is required for Bootstrap, icons and online product images.
